# 🚀 Ahmed Elmogy — Front-End Developer Portfolio

An interactive, modern, high-performance developer portfolio landing page built with **React, TypeScript, Tailwind CSS, and Framer Motion**. Features custom 3D magnetic hover physics, scroll-driven character animations, sticky stacking project cards, and connected direct contact channels.

## 🛠️ Tech Stack & Tools

- **Core & Frameworks:** React 18, TypeScript, Tailwind CSS
- **Animation & Motion:** Framer Motion (Scroll-driven transforms, sticky card stacking, magnetic mouse tracking)
- **Icons & UI:** Lucide React, Google Fonts (Kanit)
- **Build Tool:** Vite, PostCSS, Autoprefixer
- **Email Delivery:** FormSubmit / Direct Mailto fallback & WhatsApp API

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or newer recommended)
- `npm` or `yarn` or `pnpm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ahmedelmogy1/ahmed-elmogy-portfolio.git
   cd ahmed-elmogy-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for Production:**
   ```bash
   npm run build
   ```
